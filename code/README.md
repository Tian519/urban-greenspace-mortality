Code

This folder contains the R scripts used for the main statistical analyses in the study: Urban greenspace exposure and inequality are associated with mortality in cities across multiple countries

The analysis followed a two-stage framework. In the first stage, country-specific associations between greenspace metrics and mortality were estimated using negative binomial regression models. In the second stage, the country-specific estimates were pooled using random-effects meta-analysis.

Scripts
01_main_analysis.R

This script performs the first-stage country-specific analyses.
For each country, separate negative binomial regression models are fitted for:

All-cause mortality
Cardiovascular mortality
Respiratory mortality

Two greenspace metrics are evaluated separately:

Greenspace exposure: population-weighted Enhanced Vegetation Index (EVI)
Greenspace inequality: Gini index of EVI

Relative risks (RRs) and 95% confidence intervals are calculated per 0.1-unit increase in greenspace exposure or greenspace inequality.

The resulting country-specific estimates are used as inputs for the second-stage meta-analysis.

02_meta_analysis.R

This script performs the second-stage meta-analysis using the country-specific estimates generated by 01_main_analysis.R.

Random-effects meta-analysis is used to obtain pooled associations between:

Greenspace exposure and mortality
Greenspace inequality and mortality

for all-cause, cardiovascular, and respiratory mortality.

The script generates pooled relative risk estimates and corresponding 95% confidence intervals while accounting for between-country heterogeneity.

Software

Analyses were conducted using:

R version 4.4.2
glmmTMB for negative binomial regression
mixmeta for random-effects meta-analysis

Additional R packages used for data management and extraction of model estimates include dplyr, purrr, readxl, broom.mixed, and splines.

Reproducibility

The demonstration dataset is intended to illustrate the analytical workflow and data structure and does not reproduce the numerical results reported in the manuscript.
