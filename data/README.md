Data

This folder contains demonstration data used to illustrate the structure of the analytical dataset and the workflow of the accompanying R scripts.

demo_data.xlsx

demo_data.xlsx is a demonstration dataset provided to illustrate the variables and data structure used in the main analysis. The dataset is intended for code demonstration only and should not be used to reproduce or interpret the numerical results reported in the manuscript.

The analytical dataset includes variables on mortality, population, greenspace exposure, greenspace inequality, temperature, PM2.5, GDP, population age structure, and other location-level characteristics.

RR.xlsx

RR.xlsx contains country-specific relative risk estimates used to illustrate the second-stage meta-analysis workflow.

Researchers interested in accessing the original MCC mortality data should refer to the MCC Collaborative Research Network and the data-access information provided in the manuscript.

Note

The demonstration files in this folder are provided solely to allow users to understand the expected input structure and run the example analysis workflow. They are not the original analytical data used to generate the results reported in the manuscript.
